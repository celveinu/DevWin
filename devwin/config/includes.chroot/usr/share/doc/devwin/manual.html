DevWin User Manual

Version 0.1 · Built by Tech Lo Tech Hub

1. Welcome

DevWin is a desktop operating system made for developers and programmers. It looks and feels like Windows 11 with a glass finish, runs Android apps and Windows apps, and comes with tools for system development and app development ready to use.

DevWin is built by Tech Lo Tech Hub. Under the hood it uses the Linux kernel, Debian GNU/Linux 13 and the KDE Plasma desktop.

If something goes wrong, open DevWin Manual from the Start menu and go to the Troubleshooting guide, or run devwin-doctor in a terminal.

2. Getting started

Starting from a USB stick

  1. Plug in the USB stick and restart the computer.
  2. Open the boot menu (usually F12, F10, F9, Esc or Del, depending on the computer) and choose the USB stick. Choose the UEFI entry if there are two.
  3. If it will not start, turn off Secure Boot in the firmware settings and try again.

The live session logs in automatically as the user devwin. If you are ever asked for a password, it is live. In the live session, nothing you change is kept after a restart.

Installing to the disk

  1. Open the installer from the desktop or the Start menu (it is called Install Debian or Install System).
  2. Follow the steps: language, location, keyboard, disk and your user account.
  3. Back up your files first. Choosing to erase the disk deletes everything on it.
  4. When it finishes, restart and remove the USB stick.

Your first login

The first time you sign in, DevWin sets up your taskbar, theme and wallpaper. This can take up to a minute. If you are online, it also installs the VS Code extensions for Python, C and C++ in the background.

3. The desktop

  • Taskbar: at the bottom and centered. From the left: the Start button, your pinned and open apps, then the tray (network, sound, battery, notifications) and the clock.
  • Start menu: press the Start button or the Windows key, then just start typing to search for an app or a file.
  • Wallpaper and look: right-click the desktop and choose the configure option, or open System Settings.
  • System Settings: open it from the Start menu to change Wi-Fi, display, sound, power, keyboard, mouse and language.

Keyboard shortcuts

These are KDE's defaults. You can change them in System Settings, under Keyboard, then Shortcuts.

4. Everyday setup

  • Wi-Fi: click the network icon in the tray, pick your network and enter the password.
  • Bluetooth: open System Settings, then Bluetooth, and pair your device.
  • Sound: click the speaker icon in the tray to change volume and choose the output device.
  • Screen size and sharpness: System Settings, then Display. On high-resolution screens, increase the Scale.
  • Screenshots: press Print Screen to open the screenshot tool.
  • Printing: printing is not set up by default. To add it, open a terminal and run sudo apt install cups print-manager.

5. Installing and updating software

  • Discover: open Discover from the Start menu to find and install apps from Flatpak and Debian.
  • Terminal: sudo apt update, then sudo apt install <package-name>. To search, use apt search <word>.
  • Flatpak apps: if Flathub is not set up yet, run flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo, then flatpak install flathub <app-id>.
  • Remove an app: sudo apt remove <package-name>.
  • Update everything: sudo apt update && sudo apt full-upgrade, then flatpak update. Restart afterwards if the kernel was updated. Back up important files first.

6. Android apps

DevWin runs Android apps with Waydroid.

One-time setup

  1. Sign in with the Plasma (Wayland) session. You can pick the session at the bottom of the login screen.
  2. Open a terminal and run devwin-android-setup. It downloads the Android system, which is a large download (about 1 GB or more), so use a good connection.
  3. When it finishes, Android opens in a window.

Using Android apps

  • Installed Android apps appear in the Start menu like any other app.
  • To install an APK file: waydroid app install file.apk.
  • To see installed Android apps: waydroid app list.
  • To open the full Android screen: waydroid show-full-ui.
  • To free memory when you are not using Android: waydroid session stop.

Google Play: to sign in to the Play Store, the device must be registered with Google. devwin-android-setup prints the steps at the end. The registration can take a while to take effect.

Good to know: Android apps need more memory (4 GB of RAM or more is recommended). Apps that only work on ARM processors may not run on a PC.

7. Windows apps

DevWin runs Windows apps with Wine.

  • Double-click a .exe or .msi file to open it with Wine. Installed Windows apps appear in the Start menu.
  • Bottles is an optional app that makes Wine easier, with a separate setup for each app. Install it with devwin-install-devtools bottles.
  • Many classic desktop programs and many games work well. Wine is a compatibility layer and not Windows itself, so some apps do not work. These include Microsoft Office 365, Adobe Creative Cloud, apps with kernel-level copy protection or anti-cheat, and programs that need Windows drivers.
  • For apps Wine cannot run, use a real Windows virtual machine. DevWin includes virt-manager, but you need your own Windows installation file and license.

8. For developers

What is included

  • Languages: Python, C, C++, Rust, Go, Java, Node.js, PHP and Ruby.
  • Build tools: GCC, clang, CMake, Ninja, Meson, make, ccache.
  • Debugging and analysis: gdb, lldb, valgrind, strace, perf, Wireshark.
  • Kernel, embedded and OS work: kernel build tools, ARM cross-compilers, OpenOCD, live-build and QEMU.
  • Containers and virtual machines: Docker, Podman, QEMU and virt-manager.
  • Other tools: git, GitHub CLI, Neovim, tmux, zsh, adb and fastboot.

VS Code is in the Start menu. The Python, C/C++ and CMake extensions install on first login. To run that again: devwin-vscode-setup --force.

Quick starts

# C++
mkdir hello && cd hello
printf '#include <iostream>\nint main(){ std::cout << "Hello from DevWin\\n"; }\n' > main.cpp
g++ -std=c++20 -Wall -o hello main.cpp && ./hello

# Python
python3 -m venv .venv
source .venv/bin/activate
pip install requests

Docker: docker run hello-world. If you get "permission denied", run sudo usermod -aG docker $USER, then sign out and back in.

More tools on demand: run devwin-install-devtools to install Node via fnm, Rust via rustup, Kotlin and Gradle via SDKMAN, pyenv, the .NET SDK, Flutter, Android Studio, DBeaver, Postman and Insomnia. They install into your home folder or as Flatpaks.

Virtual machines: virtualization must be turned on in the computer's firmware (often called Intel VT-x, AMD-V or SVM).

9. Appearance and performance

  • Glass effects (blur, transparency, wobbly windows): if the computer feels slow, turn them off in System Settings, under Window Management, then Desktop Effects.
  • Re-apply the DevWin look: run devwin-doctor --fix and choose the first option.
  • Rounded window corners: the effect is installed but off by default. You can try it in Desktop Effects.
  • Tips for older computers:
  • Turn off the glass effects.
  • Close Android (waydroid session stop) when you are not using it.
  • Turn off file indexing in System Settings, under Search, then File Search.
  • Use btop in a terminal to see what is using memory and CPU.
  • DevWin uses compressed memory (zram) and an out-of-memory guard (earlyoom) to stay responsive on low memory.

10. Keeping your data safe

  • Copy your Documents and project folders to an external drive or cloud storage regularly.
  • For system snapshots you can install Timeshift: sudo apt install timeshift.
  • Back up before big updates and before changing disk partitions.

11. Getting help

  • devwin-help: opens this manual. devwin-help fix opens the Troubleshooting guide. devwin-help --text shows the manual in the terminal.
  • devwin-doctor: checks your system for common problems and suggests fixes.
  • devwin-doctor --fix: offers safe one-step fixes (re-apply the look, restart the desktop, sound or Android, turn glass effects on or off).
  • devwin-doctor --report: saves a report file called devwin-report.txt in your home folder. Send it to Tech Lo Tech Hub when asking for support.

Troubleshooting Guide

DevWin 0.1 · Built by Tech Lo Tech Hub

Start here: open a terminal and run devwin-doctor. It checks the most common problems and tells you what to try. For one-step fixes run devwin-doctor --fix. If you need to ask for help, run devwin-doctor --report and send the file devwin-report.txt from your home folder.

Commands that start with sudo ask for your password. Copy commands one at a time and read any message that appears.

Starting up and installing

The USB stick will not start

  • Open the boot menu and choose the UEFI entry for the USB stick.
  • Turn off Secure Boot in the firmware settings.
  • Write the USB stick again with a tool like balenaEtcher, and try a different USB port.
  • Check that the file was not damaged in the download: sha256sum -c devwin-amd64.iso.sha256. It should say OK.

Black screen or a frozen picture at start

Graphics drivers are the usual cause. At the boot menu, highlight the first entry and press e, add the word nomodeset at the end of the line that starts with linux, then press F10 to start. If that works, install the right driver after you log in.

  • NVIDIA graphics: sudo apt install nvidia-driver, then restart. If apt cannot find it, enable the non-free section in /etc/apt/sources.list and run sudo apt update.
  • AMD and Intel graphics: sudo apt update && sudo apt full-upgrade, then restart.

The installer fails

  • Check that the disk has enough free space and is not damaged.
  • Do not remove the USB stick during installation.
  • The installer keeps a log called session.log under the .cache/calamares folder of the user who ran it. Include it when asking for help.

The clock is wrong when you dual boot with Windows

Run timedatectl set-local-rtc 1 --adjust-system-clock.

I forgot my password

In the live session the password is live. On an installed system: restart, hold Shift (or press Esc) to open the boot menu, choose Advanced options, then the recovery mode entry, then root shell. Run mount -o remount,rw /, then passwd your-username, and restart.

Desktop and look

The taskbar or theme looks like plain KDE

The look is applied once, a little after your first login, and it can take up to a minute. If it still looks wrong:

  1. Run devwin-doctor --fix and choose Re-apply the DevWin look.
  2. If the desktop is broken after login: press Ctrl + Alt + F3 and sign in, run mv ~/.config/plasma-org.kde.plasma.desktop-appletsrc ~/.config/plasma-org.kde.plasma.desktop-appletsrc.bak, then restart. After the desktop loads, run devwin-doctor --fix and re-apply the look.

The desktop is slow or choppy

  • Turn off glass effects: devwin-doctor --fix, then choose the option to turn them off.
  • See what is using memory and CPU: run btop.
  • Close Android when you are not using it: waydroid session stop.
  • Turn off file indexing: System Settings, then Search, then File Search.
  • Make sure the Plasma (Wayland) session and your graphics driver are working: run devwin-doctor.

The screen flickers, or windows have strange edges

Turn off blur and rounded corners: System Settings, then Window Management, then Desktop Effects. Or run:

kwriteconfig6 --file kwinrc --group Plugins --key blurEnabled false
busctl --user call org.kde.KWin /KWin org.kde.KWin reconfigure

The computer freezes or runs out of memory

  • Run free -h to see how much memory is free.
  • Close apps you are not using, especially Android (waydroid session stop), virtual machines and browser tabs.
  • DevWin has an out-of-memory guard: systemctl status earlyoom. If an app was closed on its own, this is why.
  • Use zramctl to check that compressed memory is on.

Network, sound and Bluetooth

Wi-Fi does not work

  1. Run nmcli device status and rfkill list. If something is blocked, run sudo rfkill unblock all.
  2. Some Wi-Fi adapters need extra firmware. Run sudo dmesg | grep -i firmware to see which is missing, then install it, for example sudo apt install firmware-brcm80211 for many Broadcom adapters.
  3. Restart the network service: sudo systemctl restart NetworkManager.
  4. Connecting with a cable or a phone's USB tethering helps you download missing firmware.

There is no sound

  • Click the speaker icon in the tray and check the volume and the output device.
  • Restart the sound system: systemctl --user restart pipewire pipewire-pulse wireplumber (or devwin-doctor --fix).

Bluetooth does not work

Run sudo systemctl enable --now bluetooth and sudo rfkill unblock bluetooth, then pair the device again in System Settings.

Software and updates

apt shows errors

Try these in order:

sudo apt update --fix-missing
sudo dpkg --configure -a
sudo apt -f install
sudo apt full-upgrade

"Could not get lock" means another update is running (for example Discover). Wait for it to finish. Do not delete lock files.

The disk is full

  • Check: df -h.
  • Clean up: sudo apt clean, sudo apt autoremove, flatpak uninstall --unused.
  • Free Docker space: docker system prune (this removes unused containers and images).
  • Shrink system logs: sudo journalctl --vacuum-size=200M.

Android apps

First run devwin-doctor, which checks the points below.

Android will not start

  1. Use the Plasma (Wayland) session (choose it at the bottom of the login screen). Waydroid does not work in the X11 session.
  2. Check that the kernel supports Android: grep binder /proc/filesystems. If it prints nothing, this kernel cannot run Android apps.
  3. Restart it: waydroid session stop sudo systemctl restart waydroid-container waydroid session start waydroid show-full-ui
  4. If it still fails, run waydroid log and include the output when asking for help.

Android has no internet

Docker or a firewall can block Waydroid's network. Restart it with sudo systemctl restart waydroid-container (restart it again after Docker starts). If that does not help, see the Waydroid documentation at docs.waydro.id.

Google Play says the device is not certified

Register the device with Google. devwin-android-setup prints the steps. It can take a while to take effect.

An Android app crashes or will not install

Some apps only work on ARM processors. Try another version of the app, or use its web version.

Start Android again from scratch

Warning: this deletes all Android apps and data.

waydroid session stop
sudo systemctl stop waydroid-container
sudo rm -rf /var/lib/waydroid ~/.local/share/waydroid
devwin-android-setup

Windows apps

A .exe file will not open or the app crashes

  1. Check that Wine is installed: wine --version.
  2. Run the app from a terminal to see error messages: wine path/to/app.exe.
  3. Many apps need extra Windows components. Try winetricks (for example winetricks corefonts vcrun2022).
  4. Try Bottles (devwin-install-devtools bottles) with a separate setup per app.
  5. If a 32-bit app fails and you see a message about wine32: sudo dpkg --add-architecture i386 && sudo apt update && sudo apt install wine32:i386.
  6. If Wine still cannot run the app, use a Windows virtual machine with virt-manager.

Start the default Wine setup again

Warning: this deletes Windows apps installed in the default Wine folder. Run rm -rf ~/.wine.

Developer tools

VS Code is missing or its extensions are missing

  • Not installed: run devwin-install-devtools vscode.
  • No extensions: connect to the internet and run devwin-vscode-setup --force.
  • Blank or flickering window: run code --disable-gpu.
  • Reset VS Code settings (your extensions stay): move ~/.config/Code/User/settings.json away and restart VS Code.

Docker says "permission denied" or "cannot connect to the daemon"

  • Permission: sudo usermod -aG docker $USER, then sign out and back in.
  • Daemon not running: sudo systemctl enable --now docker.

Virtual machines say KVM is not available

  • Turn on virtualization in the computer's firmware (Intel VT-x, AMD-V or SVM).
  • Check: ls /dev/kvm.
  • Add yourself to the groups: sudo usermod -aG kvm,libvirt $USER, sign out and back in, and run sudo systemctl enable --now libvirtd.

Still stuck?

  1. Run devwin-doctor --report.
  2. Send the file devwin-report.txt from your home folder to Tech Lo Tech Hub, with a short description of what happened and what you tried.
